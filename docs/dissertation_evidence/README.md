# OEC Dissertation Evidence Pack

This folder contains source material and vector figures for the OEC dissertation.

- REPORT_INFORMATION.md: architecture, model roles, pipelines, results and suggested dissertation chapter outline.
- COMPLETION_AND_EVIDENCE_BASIS.md: project-level completion convention and interpretation of historical test evidence.
- VISUALS_AND_TABLES_GUIDE.md: figure and table placement.
- tables/: component catalogue, evidence registry, five-stage/nine-metric framework, functional completion scorecard and OEC-Play visual-plate index.
- figures/: vector diagrams and plots that can be embedded directly in a report.

Project-level implementation and functional completion is recorded as COMPLETED — project-owner confirmed. Historical run evidence retains its original execution scope. Quantitative performance values are reported only where a measured value exists.
